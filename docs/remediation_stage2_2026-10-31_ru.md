## Dev-server

`npm start` запускает сервер на `http://127.0.0.1:8080/index.html`, без автоматического открытия браузера. Для другого порта предусмотрен `PROJECTOR_DEV_PORT`. Сервер привязан к loopback; `allowedHosts: 'auto'` сохраняет встроенные проверки Host/Origin, `hot: true` и overlay ошибок включены.

Корень репозитория больше не раздаётся как static. Статически доступны только favicon по `/dist/favicons`; JS/CSS выдаются webpack middleware по `/dist/`. `/` и `/index.html` обслуживаются отдельным middleware после встроенных проверок безопасности. `sendFile` использует фиксированное имя и `root`, поэтому индекс корректно работает и в checkout внутри скрытого каталога. Watch для `index.html` сохранён. CSS Modules и publicPath проверены сборкой и ресурсными запросами.

Проверено на запущенном через `npm start` сервере:

- Индекс, JS/CSS и favicon возвращают 200.
- `package.json`, исходники, node_modules, документация и `.env` по HTTP возвращают 404.
- Посторонний Host и проверенный cross-site запрос к JS возвращают 403; ответы ресурсов имеют `Cross-Origin-Resource-Policy: same-origin`.
- WebSocket с посторонним Origin отклоняется, с Origin сервера получает hot/overlay/hash/ok.
- Изменение TSX и CSS приводит к новому hash; hot-update manifest и JS chunk возвращают 200, ресурс содержит тестовое изменение.
- После проверки оба временно изменённых файла восстановлены побайтно, тестовый сервер остановлен.

Подробные сообщения и статусы — в `artifacts/remediation-stage2/hmr.json`. Это первоначальная проверка HTTP/WebSocket, компиляции и hot-update ресурсов; на момент её выполнения браузер был недоступен. **Дополнение от 31.10.2026:** после настройки [Playwright](browser_testing_ru.md) пять сценариев прошли в Chromium. CSS применяется без перезагрузки страницы; изменение TSX появляется в отрисованном интерфейсе. React Fast Refresh не добавлялся; сохранение React-состояния при TSX-обновлениях не заявляется. Исторические JSON-отчёты этапа 2 сохранены; новые результаты находятся в `artifacts/playwright/results.json`.
