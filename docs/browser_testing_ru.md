# Проверки в браузере через Playwright

Настроен Playwright Test 1.64.1 с Chromium. Он запускает настоящий браузер, нажимает кнопки приложения и проверяет видимый результат. Локально на Windows в Chromium 156.0.8078.4 пять сценариев прошли 31 октября 2026 года.

## Запуск

Из корня проекта с Node.js 24.12.0 и npm 11.12.1:

```powershell
npm ci
npm run browser:install
npm run test:e2e
```

В текущем рабочем каталоге зависимости и Chromium уже установлены. Для следующих проверок достаточно `npm run test:e2e`.

```powershell
npm run test:e2e:ui
npm run test:e2e:report
npm run typecheck:e2e
```

Первая команда открывает интерактивный интерфейс Playwright для выбора и повторного запуска сценариев. Вторая открывает HTML-отчёт последнего прогона. Проверка ESLint браузерных тестов включена в `npm run lint-check`.

Сервер запускается автоматически на `http://127.0.0.1:43188`; отдельно выполнять `npm start` не требуется. Если порт занят, задайте `$env:PROJECTOR_E2E_PORT = '43189'`. Существующий сервер не переиспользуется. При необходимости можно выбрать установленный Chrome через `$env:PROJECTOR_E2E_CHANNEL = 'chrome'`, предварительно выполнив установку компонентов Playwright.

## Что проверяется

| Сценарий | Проверка |
| --- | --- |
| Создание документов | Появляются две вкладки, активную вкладку можно переключить |
| Закрытие крестиком | Отмена сохраняет изменённый документ; «Не сохранять» закрывает его |
| Закрытие через меню | Отмена сохраняет изменённый документ; последующее закрытие работает |
| Отмена «Сохранить как» | Диалог закрывается, вкладка и локальные данные проекта остаются |
| CSS и TSX | Новый цвет появляется без перезагрузки страницы; изменение TSX появляется в заголовке; исходники копии восстанавливаются |

Каждый тест использует отдельный браузерный контекст с пустым localStorage и проверяет отсутствие необработанных JavaScript-ошибок. Проверка TSX допускает полную перезагрузку; сохранение состояния React не проверяется.

## Изоляция и артефакты

`scripts/start-e2e-server.mjs` копирует исходники, favicon и конфигурацию в `.remediation-tmp/playwright-*`. Зависимости берутся из корневого `node_modules`; пути типов TypeScript разрешаются в него. HMR-тест меняет только эту временную копию и восстанавливает файлы в `finally`. Корневой `.env` не копируется и не читается тестовым сервером: рабочий каталог переносится в копию, где создаётся `.env` с фиктивными ключами; эти же значения задаются в окружении процесса. При штатном завершении сервера временная копия удаляется; принудительное завершение процесса Windows может оставить её в игнорируемом каталоге.

Google GSI и GAPI подменяются на сетевой границе, остальные внешние HTTP-запросы блокируются. Проверки не используют пользовательский профиль браузера, OAuth и реальный Drive. Вход, синхронизация с Drive, внешние шрифты и сетевые иконки этими сценариями не проверяются.

Отчёты сохраняются в игнорируемом каталоге `artifacts/playwright`:

- `report/index.html` — HTML-отчёт;
- `results.json` — результаты для программного разбора;
- `results` — снимки экрана; при ошибке также screenshot, trace и видео;
- `server.json` — путь временной копии и PID сервера.

После установки Playwright также прошли оба typecheck, ESLint (0 ошибок, 12 прежних предупреждений), 3516 тестов Jest, production-сборка и `build:pages` (14 файлов). Дерево `npm ls --all` корректно. Повторный аудит: 0 critical/high, 27 moderate, 4 low; production — 0. Сводка и хеши проверенных файлов сохранены в `artifacts/playwright/verification.json`, JSON аудитов — в том же каталоге.

В GitHub Actions добавлены установка Chromium с системными зависимостями, проверка типов и браузерные тесты перед сборкой Pages. Отчёт загружается как `playwright-report` со сроком хранения семь дней. Запуск GitHub Actions будет проверен после push; локальный прогон выполнен на Windows.

Конфигурация: `playwright.config.ts`; сценарии: `e2e/documents.spec.ts`, `e2e/hmr.spec.ts`; сетевые заглушки: `e2e/fixtures.ts`. Документация Playwright: [запуск тестов](https://playwright.dev/docs/intro), [webServer](https://playwright.dev/docs/test-webserver), [CI](https://playwright.dev/docs/ci-intro).
